# Captura Y Conquista De Territorios (Pag.14)

1. Para la conquista de territorios, <mark style="color:green;">Solo podrá acudir el Ejercito Nacional</mark>, la Policía Nacional no podrá intervenir
2. Si la facción tiene uniforme tendrá que ingresar con este, en caso omiso los miembros serán sancionados por <mark style="color:green;">ICN,</mark> Si se llega a una situación de que se desconectan o evaden la sanción la advertencia faccionaria será aplicada.
3. Solo se permiten disputas entre <mark style="color:green;">2 facciones</mark>, si una abate a la otra por completo podrán capturar el territorio
4. Al ingresar a la zona del territorio en medio de una disputa, los participantes tienen el derecho a abatir sin previo aviso a cualquier civil (menos funcionarios públicos)
5. Al capturar o conquistar una zona, deberán enviar un entorno para validar la captura
6. El sistema de captura solo funciona si hay <mark style="color:green;">3 militares</mark> conectados y si hay <mark style="color:green;">3 miembros de la facción dentro de la zona.</mark>
7. No se podrán utilizar <mark style="color:red;">vehículos deportivos</mark> para las conquistas (solo camionetas y automóviles).
