# Normativa de Robos

### Robos Organizados

{% hint style="info" %}
Los robos organizados solo los pueden realizar las **organizaciones ilegales.**
{% endhint %}

En este tipo de robos es <mark style="color:$success;">**obligatorio**</mark> esperar a la policía, ya sea para negociar tu huida o para cortar negociaciones e iniciar un tiroteo.

{% tabs %}
{% tab title="Robos Pequeños" %}
**Robos Básicos**

En esta categoría aplica el robo a **Tiendas Pequeñas.**

* Policías permitidos: **3** (+2 Policías si es huida)
* Ladrones permitidos: **3** (+1 Ladrón externo si es huida)
* Tirador permitido: **No permitido**
* Armamento permitido: **Armas de bajo calibre**.
* Rehenes máximos permitidos (NPC): **2**
* Helicóptero policial: **No permitido**
* Granadas (Humo/Flash/Molotov): **No permitidas**
{% endtab %}

{% tab title="Robos Medianos" %}
**Robos Medianos**
{% endtab %}

{% tab title="Robos Grandes" %}
**Robos Grandes**

En esta categoría aplica el robo a **Banco Central.**

* Policías permitidos: **6** (+6 Policías si es huida)
* Ladrones permitidos: **6** (+3 Ladrones externos si es huida)
* **Ladrones mínimos: 6**
* Tirador permitido: **Si** (Debe ser uno de los 6)
* Armamento permitido: **Armas de alto calibre**
* Rehenes máximos permitidos (NPC): **4**
* Helicóptero policial: **Permitido**
* Granadas (Humo/Flash/Molotov): **Máximo 1 de cada tipo**

Los delincuentes podrán huir **con 2 vehículos**, los 2 vehículos deben ser **autos**. En caso de huir en un (1) vehículo, este también **debe ser un auto.**
{% endtab %}
{% endtabs %}

{% hint style="danger" %}
Nota: Persona que incumpla alguna de estas reglas podrá ser sancionada por ICN u otros conceptos según indique la falta presentada.
{% endhint %}
