# Comandos Principales

{% tabs %}
{% tab title="/DO" %}
El comando <mark style="color:green;">/do</mark> se utiliza para detallar el entorno que rodea a nuestro personaje, también para dar respuesta a escenarios puntuales, debe usarse de manera neutral y no para nuestro favor.

Este comando no se usa para pensar.
{% endtab %}

{% tab title="/ME" %}
El comando <mark style="color:green;">/me</mark> se utiliza para realizar acciones con nuestro personaje, las cuales no pueden ser representadas por alguna animación dentro del juego. El uso de este comando debe ser neutral sin beneficio propio.
{% endtab %}

{% tab title="/B" %}
Este comando es utilizado para enviar mensajes fuera de rol a los jugadores cercanos. En el servidor está como <mark style="color:green;">Bindkey (B) o comando /b.</mark>
{% endtab %}

{% tab title="/DUDA" %}
Este comando se usa para comunicarte con un staff vía <mark style="color:green;">IC</mark>, para solucionar dudas y problemas de rol o del servidor en general.
{% endtab %}
{% endtabs %}
